# CreatorX

CreatorX 是基于 **LeviLamina** 的 Minecraft 基岩版 WorldEdit 式快速建造模组，支持 **专用服务端（BDS）** 与 **Windows 客户端（单人 / 局域网主机）**。

---

## 核心功能

- **选区与统计**：魔杖设点、坐标与准星设点、单向/六面扩缩与平移、方块计数与分布统计；自动适配实线框与粒子边框。
- **图案与掩码**：支持单方块、精确方块状态（`wool[color=red]`）、权重随机混合（`60%stone,40%andesite`）、手持方块（`hand` / `offhand`）、掩码交并集与取反，输错方块名自动拼写纠错。
- **编辑、生成与笔刷**：填充、替换、四壁、外壳、掏空、表层覆盖、中心标记、移动、堆叠；球体/椭球、圆柱、金字塔生成；球形/圆柱/平滑/重力/剪贴板笔刷与信息/替换工具。
- **剪贴板与原理图**：复制、剪切、粘贴（含含水层、方块实体 NBT 与可选生物实体），支持假方块预览与微调、三维 90° 旋转、镜像翻转；支持 `.mcstructure`、`.cxs`、`.schem`、`.litematic` 导入导出与直接放置。
- **持久化历史与防卡服调度**：多步撤销/重做（支持管理员回滚他人操作）、超限自动溢写磁盘、退服保留记录；大操作按区块分 tick 异步执行，支持弹窗确认与随时取消。
- **图形菜单与客户端增强**：`/cx menu`（或蹲下右键魔杖）覆盖选区、分类方块浏览器、建造、变换、原理图全流程；客户端额外提供 `F6`–`F10` 快捷键与动作栏状态 HUD。

## 安装与环境要求

- **环境**：Windows x64，Minecraft 基岩版 / BDS `1.26.60`（**LeviLamina `26.60.*`**）。
- **使用 lip 安装**：
  ```powershell
  # 专用服务端（BDS）
  lip install github.com/yangyangzhong82/CreatorX

  # Windows 客户端
  lip install github.com/yangyangzhong82/CreatorX#client
  ```
- 手动安装与双端搭配说明见 [第 1 章：快速上手与安装](docs/01-快速上手与安装.md)。

## 30 秒上手

1. **领取魔杖**：游戏内拥有 OP 权限后，输入 `/cx wand` 领取选区魔杖（或输入 `/cx menu` / 蹲下右键魔杖打开图形菜单）。
2. **框选区域**：手持魔杖**左键**设点 1，**右键**对角方块设点 2。
3. **执行建造**：输入 `/cx set 60%stone_bricks,40%mossy_stone_bricks` 填充，或在菜单中操作。
4. **撤销与中止**：输入 `/cx undo` 撤销，`/cx redo` 重做，任务运行中可输入 `/cx cancel` 中止。

> 默认开启短命令（`command.shortCommands: true`），选区、编辑、剪贴板、原理图与历史命令均可省略 `/cx` 直接输入（如 `/wand`、`/pos1`、`/set stone`、`/undo`）。`/cx brush`、`/cx tool` 等笔刷相关命令需保留 `/cx` 前缀。
