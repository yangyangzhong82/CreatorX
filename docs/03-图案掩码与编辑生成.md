# 第 3 章：图案、掩码与编辑生成

这是 CreatorX 最具创造力的章节。搞懂 **图案（Pattern：决定往外放什么方块）** 与 **掩码（Mask：决定哪些原有方块允许被动刀）** 这两个概念，你就能用短短一行命令做出丰富细腻的建筑纹理。

---

## 3.1 图案语法（Pattern）——“放什么方块？”

凡是命令中写着 `<pattern>`（图案）的地方，都可以填写以下任意一种写法，也支持用英文逗号 `,` 把多个方块组合起来随机混搭：

| 写法类型 | 语法示例 | 详细说明 |
| --- | --- | --- |
| **普通方块名** | `stone`<br>`minecraft:oak_planks` | 可省略 `minecraft:` 前缀，大小写不敏感。使用 `/cx set <方块名>` 时自带原版全方块命令补全 |
| **手持方块** | `hand`<br>`offhand` | 直接取你**主手**（`hand`）或**副手**（`offhand`）正拿着的方块，懒得查英文 ID 时最好用！ |
| **带精确方块状态** | `wool[color=red]`<br>`oak_stairs["upside_down_bit"=true,"weirdo_direction"=2]` | 用方括号 `[键=值,...]` 指定基岩版方块状态（支持布尔值 `true`/`false`、整数、带引号或不带引号的字符串；方括号内的逗号不会被误拆） |
| **百分比随机混合** | `60%stone,30%cobblestone,10%andesite`<br>`50%stone_bricks,mossy_stone_bricks,cracked_stone_bricks` | 按权重在每个格子随机挑一种放置，做旧墙面和自然地形神器！<br>• 没写 `%` 的条目会自动**平分剩余的 `100%` 份额**（例如第二行后两项各占 `25%`）。<br>• 若已写百分比加起来已经 `>= 100`，未写百分比的条目按权重 `1` 参与分配。 |

### 贴心防呆机制
- **智能拼写纠错**：如果不小心把 `stone` 打成了 `stnoe`，CreatorX 会自动对比全服方块表并提示：`未知方块 'minecraft:stnoe'，你是不是想输入 'minecraft:stone'？`
- **危险方块黑名单**：默认禁止通过图案放置命令方块、结构方块和屏障（可在 `config.jsonc` 的 `limits.disallowedBlocks` 中修改），防止熊孩子或误操作破坏服务器安全。

## 3.2 掩码语法（Mask）——“只改哪些方块？”

在替换（`replace`）、按条件复制（`copy -m`）、方块计数（`count`）等场景中，**掩码**就像一张筛网，用来过滤哪些格子才会被匹配：

- **英文逗号 `,` = 或（满足其一即可）**：例如 `dirt,grass_block` 匹配泥土**或**草方块。
- **感叹号 `!` = 非（排除 / 取反）**：例如 `!air` 匹配除了空气以外的一切方块；`!stone,dirt` 排除石头和泥土。
- **空格 ` ` = 且（必须同时满足）**：多个条件词之间用空格隔开表示取交集，例如 `#solid !bedrock` 表示“既是实心方块，又不是基岩”。

| 掩码写法 | 示例 | 匹配规则 |
| --- | --- | --- |
| **方块类型（忽略变体）** | `wool`、`oak_stairs` | 不带 `[...]` 时，匹配该方块 ID 的**所有颜色/朝向变体** |
| **精确状态匹配** | `wool[color=red]` | 带 `[...]` 时，**只匹配完全符合该状态**的方块（其他颜色羊毛不动） |
| **手持方块匹配** | `hand`、`offhand` | 精确匹配主手或副手拿着的同款方块及状态 |
| **内置集合 `#existing`** | `#existing` | 匹配所有**非空气**方块（等同于 `!air`） |
| **内置集合 `#solid`** | `#solid` | 匹配所有**实心**方块（自动跳过空气、花草、火把、水等非实心物） |
| **内置集合 `#air`** | `#air` | 仅匹配**空气**方块（只往空隙里填东西、不破坏原有建筑时极好用） |
| **组合交集与取反** | `!air !water`<br>`#solid !stone,cobblestone` | 同时满足空格分隔的每一项条件 |

## 3.3 区域编辑命令（需先设好选区）

下列命令作用于你当前框选好的长方体选区：

| 命令 | 短命令 | 语法 | 效果说明 |
| --- | --- | --- | --- |
| **填充整个选区** | `/cx set` | `/cx set <图案>` | 将选区内的每一格都设为指定图案（填 `air` 即清空整片区域） |
| **条件替换** | `/cx replace` | `/cx replace [原方块掩码] <新图案>` | 将选区内符合 `[原方块掩码]` 的方块换成 `<新图案>`。<br>💡 **省略掩码时默认替换 `#existing`（所有非空气方块）**！ |
| **生成四面围墙** | `/cx walls` | `/cx walls <图案>` | 只填充选区的**东、南、西、北四个垂直侧面**（不含天花板和地板，内部保持原样） |
| **生成六面外壳** | `/cx faces`<br>`/cx outline` | `/cx faces <图案>`<br>`/cx outline <图案>` | 填充选区的**全部六个外表面**（上下底面 + 四壁，做封闭房间外壳，`outline` 是完全等价的别名） |
| **掏空内部** | `/cx hollow` | `/cx hollow [外壳厚度] [内部填充图案]` | 保留选区外围 `[外壳厚度]` 格（默认 `1` 格）不动，把中心内部全部填为 `[图案]`（默认填 `air` 挖空） |
| **表层覆盖** | `/cx overlay` | `/cx overlay <图案>` | 在选区每一竖列（X, Z）**最高的实心方块正上方一格**铺设 `<图案>`（即使最高实心方块正好在选区顶面，也会贴心地在它头顶 `max.y + 1` 处铺上！） |
| **标记几何中心** | `/cx center` | `/cx center <图案>` | 在选区正中心点放置 `<图案>`，找对称建筑中轴线必备 |

**高频实战口诀**：
- **清空场地**：`/cx set air`
- **给已有建筑一键换材质（保留空气造型不变）**：`/cx replace quartz_block`
- **只往选区空隙里灌水，不冲毁原有建筑**：`/cx replace #air water`
- **把荒山表面铺一层草皮或积雪**：框选山体后执行 `/cx overlay snow_layer` 或 `/cx overlay moss_carpet`
- **把实心大方块掏成壁厚 2 格的空心堡垒**：`/cx hollow 2`

## 3.4 区域移动与重复堆叠（`move` / `stack`）

盖好了一截城墙、一节铁轨或一层标准楼层后，用 `move` 和 `stack` 可以瞬间完成平移和成倍扩建（自动连同含水层与箱子等方块实体一起搬运）：

| 命令 | 短命令 | 语法 | 效果说明 |
| --- | --- | --- | --- |
| **移动建筑** | `/cx move` | `/cx move [格数] [方向] [-a] [-s]` | 将选区内的建筑整体向指定方向挪动 `[格数]` 格（默认 `1` 格），原位置自动清空为空气 |
| **重复堆叠** | `/cx stack` | `/cx stack [次数] [方向] [-a] [-s]` | 将选区沿指定方向紧挨着自身尺寸连续复制 `[次数]` 份（默认 `1` 份） |

- **`[方向]`**：省略时自动取你**当前镜头朝向**；也可显式指定 `up`、`down`、`north`、`south`、`east`、`west`。
- **`-a`（跳过空气）**：选区里的空气不会覆盖掉目标位置原本已有的地形或建筑。
- **`-s`（选区跟随）**：操作完成后，自动把你的绿色选区框移动到新位置（或最后一份堆叠物上），方便连续调整。

**示例**：
- **盖摩天大楼**：建好第 1 层并框选它，抬头看天输入 `/cx stack 15`（或直接输入 `/cx stack 15 up`），15 层高楼一秒拔地而起！
- **修跨海大桥**：造好一段桥面并框选，面朝大海对岸输入 `/cx stack 20 -a`。
- **房子建偏了 3 格**：框选整栋房子，输入 `/cx move 3 east -s` 往东平移 3 格且选区跟着过去。

## 3.5 几何形状生成（无需事先设选区！）

以下 6 条生成命令**不需要提前设置选区**，它们直接以**你当前脚下所在方块坐标**作为基准点生成（最大半径/层数上限为 `512`，圆柱最大高度 `2048`）：

| 命令 | 短命令 | 语法 | 形状说明 |
| --- | --- | --- | --- |
| **实心球 / 椭球** | `/cx sphere` | `/cx sphere <图案> <r>[,ry,rz] [-r]` | 以脚下为球心生成实心球体；若用逗号写 3 个半径 `<rx,ry,rz>` 则生成**三轴椭球** |
| **空心球 / 椭球** | `/cx hsphere` | `/cx hsphere <图案> <r>[,ry,rz] [-r]` | 生成 1 格壁厚的空心球壳或空心椭球（做玻璃生态穹顶极佳） |
| **实心圆柱** | `/cx cyl` | `/cx cyl <图案> <r>[,rz] [高度]` | 从脚下高度向上生成实心圆柱（或椭圆底面柱 `<rx,rz>`），`[高度]` 省略时默认为 `1`（即平铺圆盘） |
| **空心圆柱** | `/cx hcyl` | `/cx hcyl <图案> <r>[,rz] [高度]` | 生成空心圆筒 / 圆形围墙 / 圆形塔楼外墙 |
| **实心金字塔** | `/cx pyramid` | `/cx pyramid <图案> <层数>` | 从脚下那一层开始逐层向内收缩，生成 `<层数>` 高的实心方锥金字塔 |
| **空心金字塔** | `/cx hpyramid` | `/cx hpyramid <图案> <层数>` | 生成内部中空的金字塔外壳 |

### 球体专属 `-r`（抬高球心）参数
默认情况下，`sphere` 和 `hsphere` 的球心就在你脚下，所以下半个球会埋进地底。如果你希望**球体底部刚好踩在你脚下的地面上**，在最后加上 `-r` 即可把球心自动向上抬高 `ry` 格！

**示例**：
- **在地面立起一座半径 12 的空心玻璃球馆**：`/cx hsphere glass 12 -r`
- **生成扁平飞碟状石头浮空岛（X/Z 半径 20，高度半径 6）**：飞到空中执行 `/cx sphere 70%stone,30%cobblestone 20,6,20`
- **修一座半径 8、高 25 格的石砖圆形瞭望塔筒身**：`/cx hcyl stone_bricks 8 25`
- **铺一块半径 10 的圆形木地板**：`/cx cyl oak_planks 10`（高度省略即为 1 层圆盘）
- **造一座 20 层高的砂岩空心金字塔**：`/cx hpyramid sandstone 20`
