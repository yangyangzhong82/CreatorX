# 第 3 章：图案、掩码、编辑与笔刷

本章介绍图案与掩码语法、选区编辑、几何形状生成，以及绑定到手持物品的笔刷与工具。

---

## 3.1 图案语法（Pattern）

图案决定“放置什么方块”，支持单个方块、随机混合与精确方块状态：

| 类型 | 示例 | 说明 |
| --- | --- | --- |
| 普通方块 | `stone`、`minecraft:oak_planks` | 可省略 `minecraft:`，不区分大小写 |
| 手持方块 | `hand`、`offhand` | 读取主手或副手正拿着的方块与状态 |
| 指定状态 | `wool[color=red]`<br>`oak_stairs["upside_down_bit"=true,"weirdo_direction"=2]` | 用 `[键=值,...]` 指定基岩版方块状态 |
| 百分比混合 | `60%stone,30%cobblestone,10%andesite`<br>`50%stone_bricks,mossy_stone_bricks,cracked_stone_bricks` | 英文逗号分隔；未写 `%` 的项平分 `100%` 剩余比例（若已写合计 `>= 100`，未写项按权重 `1` 参与） |

- **拼写纠错**：输错方块 ID 时，系统会按编辑距离提示最接近的方块名。
- **黑名单拦截**：`config.jsonc` 中 `limits.disallowedBlocks` 列出的方块（默认含命令方块、结构方块、屏障）禁止通过图案放置。

---

## 3.2 掩码语法（Mask）

掩码决定“只修改哪些原有方块”，用于 `replace`、`copy -m`、`count`、笔刷等场景：

- **逗号 `,` = 或**：`dirt,grass_block` 匹配泥土或草方块。
- **感叹号 `!` = 非**：`!air` 匹配除空气外的所有方块；`!stone,dirt` 排除石头和泥土。
- **空格 ` ` = 且**：`#solid !bedrock` 匹配既是实心又不是基岩的方块。

| 写法 | 示例 | 匹配规则 |
| --- | --- | --- |
| 方块名 | `wool`、`oak_stairs` | 不写 `[...]` 时匹配该方块的**所有状态变体** |
| 带状态 | `wool[color=red]` | 只匹配状态完全一致的方块 |
| 手持方块 | `hand`、`offhand` | 匹配主/副手方块及状态 |
| `#existing` | `#existing` | 所有非空气方块 |
| `#solid` | `#solid` | 所有实心方块 |
| `#air` | `#air` | 仅空气方块 |

## 3.3 区域编辑命令（需先设选区）

| 命令 | 短命令 | 语法 | 说明 |
| --- | --- | --- | --- |
| 填充 | `/set` | `/cx set <图案>` | 将选区全部填充为指定图案（填 `air` 即清空） |
| 替换 | `/replace` | `/cx replace [原方块掩码] <新图案>` | 将匹配掩码的方块替换为新图案；省略掩码默认替换 `#existing` |
| 四壁 | `/walls` | `/cx walls <图案>` | 仅填充四周垂直围墙（不含顶面与底面） |
| 外壳 | `/faces` / `/outline` | `/cx faces <图案>` | 填充全部六个外表面（`outline` 为别名） |
| 掏空 | `/hollow` | `/cx hollow [厚度] [内部图案]` | 保留外壳（默认厚 `1` 格），内部填为指定图案（默认 `air`） |
| 表层覆盖 | `/overlay` | `/cx overlay <图案>` | 在选区每列最高实心方块正上方一格铺设图案 |
| 中心标记 | `/center` | `/cx center <图案>` | 在选区几何中心放置方块 |

**常用示例**：
- `/cx replace quartz_block`：将选区内所有非空气方块替换为石英块。
- `/cx replace #air water`：只向选区空隙注水，保留原有建筑。
- `/cx overlay snow_layer`：在山体表面铺一层积雪。

## 3.4 移动与堆叠（`move` / `stack`）

自动同步搬运含水层与方块实体 NBT（含大箱子配对）：

| 命令 | 短命令 | 语法 | 说明 |
| --- | --- | --- | --- |
| 移动 | `/move` | `/cx move [格数] [方向] [-a] [-s] [-e] [-m <掩码>]` | 将选区内建筑平移 `[格数]`（默认 `1`），原位置清空 |
| 堆叠 | `/stack` | `/cx stack [次数] [方向] [-a] [-s] [-e] [-m <掩码>]` | 按选区自身尺寸向指定方向连续复制 `[次数]` 份（默认 `1`） |

**参数**：
- `[方向]`：省略时取玩家当前视线方向；也可指定 `up`、`down`、`north`、`south`、`east`、`west`。
- `-a`：跳过空气，不覆盖目标区域原有方块。
- `-s`：操作完成后将选区框移动到新位置。
- `-e`：连同非玩家实体一起移动或堆叠。
- `-m <掩码>`：仅搬运符合掩码的方块（必须放在命令最后）。

**示例**：`/cx stack 15 up` 可将选中单层建筑向上堆叠 15 层。

## 3.5 几何形状生成（无需选区）

默认以**脚下所在方块**为基准点，最大半径/层数 `512`，圆柱最大高度 `2048`。

| 命令 | 短命令 | 语法 | 说明 |
| --- | --- | --- | --- |
| 实心球 / 椭球 | `/sphere` | `/cx sphere <图案> <r>[,ry,rz] [-r] [-c] [-m <掩码>]` | 填 `rx,ry,rz` 生成三轴椭球 |
| 空心球 / 椭球 | `/hsphere` | `/cx hsphere <图案> <r>[,ry,rz] [-r] [-c] [-m <掩码>]` | 生成单层表皮空心球或椭球 |
| 实心圆柱 | `/cyl` | `/cx cyl <图案> <r>[,rz] [高度] [-c] [-m <掩码>]` | 填 `rx,rz` 生成椭圆柱；省略高度默认 `1`（圆盘） |
| 空心圆柱 | `/hcyl` | `/cx hcyl <图案> <r>[,rz] [高度] [-c] [-m <掩码>]` | 生成空心圆筒壁（无上下盖） |
| 实心金字塔 | `/pyramid` | `/cx pyramid <图案> <层数> [-c] [-m <掩码>]` | 从基准层向上收缩生成实心四棱锥 |
| 空心金字塔 | `/hpyramid` | `/cx hpyramid <图案> <层数> [-c] [-m <掩码>]` | 生成空心金字塔外壳 |

**通用选项**：
- `-r`（仅球体）：将球心向上抬高 `ry` 格，使球底刚好落在基准点上。
- `-c`：改以**当前选区中心**作为基准点（需已设置完整选区）。
- `-m <掩码>`：仅在目标位置符合掩码时写入（放命令最后，例如 `-m #air` 只在空气处生成）。

## 3.6 笔刷与手持工具（须带 `/cx` 前缀）

将笔刷或工具绑定到**当前主手物品**（按物品 ID 绑定，不影响其他物品），绑定后对准远处目标点击即可生效。装有增强客户端时，手持笔刷还会显示准星落点提示。

### 绑定笔刷（右键使用，默认半径 `3`、射线距离 `32`）

| 命令 | 语法 | 说明 |
| --- | --- | --- |
| 球形笔刷 | `/cx brush sphere <图案> [半径] [-h]` | 在准星命中处生成实心球（加 `-h` 空心） |
| 圆柱笔刷 | `/cx brush cyl <图案> [半径] [高度] [-h]` | 在准星命中处生成圆柱（加 `-h` 空心） |
| 平滑笔刷 | `/cx brush smooth [半径] [次数]` | 平滑周围地形高度（次数 `1–10`，默认 `1`） |
| 重力笔刷 | `/cx brush gravity [半径]` | 使范围内悬空方块向下落到实心地面 |
| 剪贴板笔刷 | `/cx brush clipboard [-a] [-o]` | 将当前剪贴板内容粘贴到准星命中点；`-a` 跳过空气，`-o` 原位粘贴 |

### 绑定手持工具（支持左键与右键）

| 命令 | 语法 | 操作说明 |
| --- | --- | --- |
| 信息工具 | `/cx tool info` | **左键或右键**显示目标方块的坐标、ID、方块状态与方块实体 NBT |
| 单格替换工具 | `/cx tool repl <图案>` | **左键**吸取目标方块及状态设为当前材质，**右键**将目标方块替换为当前材质 |

### 调整参数与解绑（手持已绑定物品执行）

- `/cx size <1-64>`：调整球形、圆柱、平滑或重力笔刷的半径。
- `/cx mat <图案>`：更换球形、圆柱笔刷或替换工具的材质。
- `/cx mask [掩码]`：为笔刷设置过滤掩码；省略 `[掩码]` 则清除掩码。
- `/cx range <1-128>`：设置射线最大作用距离。
- `/cx none`：解除当前手持物品的绑定。
