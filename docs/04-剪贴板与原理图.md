# 第 4 章：剪贴板与原理图

CreatorX 为每位玩家维护一份**自动持久化保存**的剪贴板——即使你中途退出游戏或重启服务器，上次复制好的建筑依然留在剪贴板里随时可贴！同时支持把剪贴板保存为原理图文件，在不同建筑师或不同世界存档之间自由分享。

---

## 4.1 相对站位法则（为什么粘贴出来位置偏了？）

新手最容易困惑的一点是：**“为什么我点粘贴，建筑没有生成在我正脚下，而是偏到了旁边？”**

这是因为 CreatorX 与 WorldEdit 一样采用极其科学的**相对站位记忆机制**：
1. 当你执行 **`/cx copy`** 时，模组会精确记下**选区相对于你当时脚下位置的偏移量**。
2. 当你走到新地方执行 **`/cx paste`** 时，建筑会按**一模一样的相对位置**生成。

> **黄金技巧**：复制一栋房子时，**建议站在这栋房子大门口正前方的地面上执行 `/cx copy`**。这样当你走到新地块的路边，面朝同一个方向输入 `/cx paste` 时，新房子的大门就会严丝合缝地正好落在你面前！

## 4.2 复制、剪切与粘贴

剪贴板默认自动保留：
- **基础方块与精确状态**（颜色、朝向、半砖上下位等）；
- **方块第二层（Extra Layer）**（如含水楼梯、含水栅栏中的水不会丢失）；
- **方块实体（Block Actor）NBT**（箱子/木桶里的物品、告示牌文字、旗帜图案等，甚至连**双格大箱子的左右配对坐标**都会自动重新对齐！）。

| 命令 | 短命令 | 语法 | 功能说明 |
| --- | --- | --- | --- |
| **复制选区** | `/cx copy` | `/cx copy [-e] [-m <掩码>]` | 将选区读入剪贴板（不改动原世界） |
| **剪切选区** | `/cx cut` | `/cx cut [留下的图案] [-e] [-m <掩码>]` | 先将选区读入剪贴板，随后把原选区填充为 `[留下的图案]`（省略时默认填 `air` 清空） |
| **粘贴建筑** | `/cx paste` | `/cx paste [-a] [-o] [-s] [-p] [-e] [-m <掩码>]` | 将剪贴板内容放置到世界中 |
| **清空剪贴板** | `/cx clearclipboard` | `/cx clearclipboard` | 清空你的剪贴板并释放存储空间 |

### 标志位参数（Flags）全解
多个单字母开关既可以分开写（如 `-a -p -s`），也可以连在一起写（如 **`-aps`**）。**注意：如果使用了 `-m <掩码>`，必须把 `-m` 放在整条命令的最后面**，因为它后面的所有内容都会作为掩码解析！

| 参数 | 适用命令 | 作用详解 |
| :---: | :---: | --- |
| **`-a`** | `paste` | **跳过空气（Skip Air）**：剪贴板里的空气格不会覆盖掉目标场地原本的地形或树木，贴不规则建筑必加！ |
| **`-p`** | `paste` | 显示仅本人可见的预览假方块和橙色边界，可以移动和转头检查落点。用 `/cx confirm` 或剪贴板菜单确认，`/cx cancel` 或超时会清除预览。超过 `visual.previewMaxBlocks`（默认 4096 格）时只显示边界。 |
| **`-s`** | `paste` | **自动选中落点（Select）**：粘贴完成后，自动把选区框设为刚贴出来的这块建筑范围 |
| **`-o`** | `paste` | **原位粘贴（Origin）**：无视你当前站在哪，强制贴回当初 `/cx copy` 时的原始世界绝对坐标 |
| **`-e`** | `copy` / `cut` / `paste` | **包含实体（Entities）**：复制时带上选区内除玩家以外的所有实体（盔甲架、画、展示框、矿车、生物等）；剪切时一并移除原实体；粘贴时在新位置生成它们（**需复制时加了 `-e`，且粘贴时也加 `-e` 才会放出实体**） |
| **`-m <掩码>`** | `copy` / `cut` / `paste` | **掩码过滤（放最后）**：仅复制、仅剪切或仅粘贴符合 `<掩码>` 条件的方块 |

预览期间可以执行 `/cx pastepreview <dx> <dy> <dz> [Y轴角度]`，或在剪贴板菜单选「调整预览落点」。偏移从当前落点开始计算，旋转以当前落点的最小角为基准。调整后重新计时，默认 30 秒。

**实用示例**：
- **最稳妥的日常粘贴（跳过空气 + 先看预览确认 + 贴完自动框选）**：
  ```text
  /cx paste -aps
  /cx confirm
  ```
- **连同屋里的盔甲架、画框和村民一起搬家**：
  ```text
  /cx copy -e
  /cx paste -ae
  ```
- **只把选区里的矿石抠出来复制走**：
  ```text
  /cx copy -m !stone,deepslate,dirt,air
  ```

## 4.3 旋转与翻转剪贴板（智能方块朝向变换）

复制好的房子大门朝南，但新场地需要大门朝东？不需要重盖，直接在剪贴板里旋转或翻转后再粘贴！

| 命令 | 短命令 | 语法 | 功能说明 |
| --- | --- | --- | --- |
| **三维旋转** | `/cx rotate` | `/cx rotate <Y轴角度> [X轴角度] [Z轴角度]` | 将剪贴板按 **90° 的整数倍**（如 `90`、`180`、`270`、`-90`）旋转。通常水平转向只需填第一个 `<Y轴角度>` |
| **镜像翻转** | `/cx flip` | `/cx flip [方向]` | 省略方向时按玩家当前朝向镜像。可用 `east`/`west`（X 轴）、`north`/`south`（Z 轴）、`up`/`down`（Y 轴）。 |

### 自动联动旋转的细节
CreatorX 不仅旋转方块坐标，还会**自动换算复杂方块的朝向状态与实体姿态**：
- **自动修正朝向**：楼梯（含倒置楼梯）、半砖上下位、原木柱轴向（`pillar_axis`）、门（含门铰链左右手自动镜像）、活板门、火把、拉杆、藤蔓、铁轨弯道与坡道、16 方向立式告示牌等均会自动跟着转到正确方向。
- **自动旋转相对站位与实体**：你的复制相对站位（`offset`）、大箱子配对以及 `-e` 复制进来的实体坐标与朝向视角（Yaw / Pitch）都会同步旋转。
- **物理限制保护**：如果剪贴板内含有在原版基岩版中根本不存在对应侧躺变体的方块（例如尝试把普通铁轨或立式告示牌绕 X 轴侧翻 90°），命令会安全报错拦截并保持原剪贴板完好无损。

**对称建造连招示例**：
1. 只修好宏伟宫殿的**左半边**并框选它。
2. 站在宫殿中轴线上执行 `/cx copy`。
3. 原地不动，执行 `/cx flip east`（左右镜像翻转剪贴板）。
4. 执行 `/cx paste -ap` 检查预览，再用 `/cx confirm` 落地。

## 4.4 原理图管理

文件存放在运行世界的一端的 `mods/creatorx/data/schematics/`。使用 `/cx schem` 或「复制 / 粘贴 → 原理图管理」导出选区、加载剪贴板或直接放置。文件读取上限为 256 MiB，Java 格式也按解压后的大小检查。

| 格式 | 读写范围 |
| --- | --- |
| `.mcstructure` | 与基岩版结构方块交换，保留方块状态、含水、箱子和告示牌等方块实体，可选保留非玩家实体 |
| `.cxs` | CreatorX 剪贴板格式，保留原始位置和复制时的站位偏移 |
| `.schem` | WorldEdit / Sponge，读取 v1–v3，写入 v3 |
| `.litematic` | Java 版 Litematica 投影，支持读取多子区域和负尺寸，写入单区域 |

Java 格式使用适配 Java 26.3 和基岩 26.60 的方块状态映射。跨版本转换可能简化方块属性或跳过没有对应状态的方块。方块实体 NBT、实体、生物群系和计划刻不参与 Java 格式转换。映射资料来自 [GeyserMC](https://github.com/GeyserMC/mappings)。

| 子命令 | 完整语法 | 说明 |
| --- | --- | --- |
| 导出选区 | `/cx schem export <文件> [格式] [-e]` | 直接保存当前选区。`-e` 可在基岩格式中一并导出非玩家实体 |
| 放置文件 | `/cx schem place <文件> [格式] [-a] [-e]` | 将结构最小角放在执行命令时的脚下。`-a` 跳过空气，`-e` 放置基岩格式保存的实体 |
| 保存剪贴板 | `/cx schem save <文件> [格式]` | 将当前剪贴板保存为文件 |
| 加载到剪贴板 | `/cx schem load <文件> [格式]` | 加载后可用 `/cx paste` 放置，也可先旋转或预览 |
| 列出 / 搜索 | `/cx schem list [关键词]` | 按文件名列出或筛选上述四种格式 |
| 删除 | `/cx schem delete <文件> [格式]` | 从目录中删除文件 |

文件名可以直接写扩展名。省略扩展名和格式时，`export` 和 `place` 默认使用 `.mcstructure`，`save`、`load` 和 `delete` 默认使用 `.cxs`。带空格的文件名用双引号括起来。

选区已经圈好时，可以直接导出。把外部文件放入 `schematics/` 后，在目标位置执行 `place`。放置记录可用 `/cx undo` 撤销。

```text
/cx schem export medieval_house.mcstructure -e
/cx schem export medieval_house.litematic
/cx schem place medieval_house.mcstructure -a -e
/cx schem place imported.schem -a
```
