# 第 4 章：剪贴板与原理图

CreatorX 为每位玩家持久保存一份剪贴板，退出游戏或重启服务器后仍可继续粘贴；同时支持将结构导出或加载为多种原理图格式。

---

## 4.1 相对偏移机制

执行 `/cx copy` 时，系统会记录**选区相对于你当时脚下坐标的偏移**；执行 `/cx paste` 时，会按**相同的相对位置**放置到你当前位置周围。

> **实用建议**：复制建筑时站在大门正前方地面上执行 `/cx copy`，到新地块面向相同方向执行 `/cx paste`，建筑大门就会正好落在你面前。

---

## 4.2 复制、剪切与粘贴

剪贴板默认保留方块状态、含水第二层（如含水楼梯/栅栏）以及箱子、告示牌等方块实体 NBT（自动修正双格大箱子配对）。

| 命令 | 短命令 | 语法 | 说明 |
| --- | --- | --- | --- |
| 复制 | `/copy` | `/cx copy [-e] [-m <掩码>]` | 将选区存入剪贴板 |
| 剪切 | `/cut` | `/cx cut [留下的图案] [-e] [-m <掩码>]` | 复制后把原选区填为指定图案（默认 `air`） |
| 粘贴 | `/paste` | `/cx paste [-a] [-o] [-s] [-p] [-e] [-m <掩码>]` | 放置剪贴板内容 |
| 清空 | `/clearclipboard` | `/cx clearclipboard` | 清空当前剪贴板 |

### 参数说明

多个单字母开关可合并书写（如 `-aps`）。**使用 `-m <掩码>` 时必须将其放在命令最后**。

| 参数 | 适用命令 | 说明 |
| :---: | :---: | --- |
| `-a` | `paste` | **跳过空气**：剪贴板里的空气不会覆盖目标位置的原有方块 |
| `-p` | `paste` | **先预览后确认**：显示仅本人可见的预览假方块和橙色边界；确认前可用 `/cx confirm` 落地，或 `/cx cancel` 取消 |
| `-s` | `paste` | **粘贴后选中**：自动将选区设为刚粘贴出的区域 |
| `-o` | `paste` | **原位粘贴**：忽略当前站位，贴回 `copy` 时的原始世界坐标 |
| `-e` | `copy` / `cut` / `paste` | **包含实体**：连同选区内除玩家外的实体（盔甲架、画、生物等）一起复制/移除/生成（需 `copy` 与 `paste` 均加 `-e`） |
| `-m <掩码>` | `copy` / `cut` / `paste` | **掩码过滤**：仅处理符合掩码的方块（放命令最后） |

### 预览微调

在 `-p` 预览期间（默认有效 `30` 秒，超出 `visual.previewMaxBlocks` 默认 `4096` 格时只显示边界），可以移动视角检查落点，并执行以下命令调整或确认：
- `/cx pastepreview <dx> <dy> <dz> [Y轴角度]`：相对当前落点平移并旋转预览（旋转以当前落点最小角为轴心），调整后重新计时。
- `/cx confirm`：确认放置。
- `/cx cancel`：取消预览并还原画面。

**示例**：
- `/cx paste -aps` → 检查后 `/cx confirm`：跳过空气 + 预览 + 贴完自动选中。
- `/cx copy -e` → `/cx paste -ae`：连同屋内实体一起搬家。

## 4.3 旋转与镜像翻转

| 命令 | 短命令 | 语法 | 说明 |
| --- | --- | --- | --- |
| 三维旋转 | `/rotate` | `/cx rotate <Y角度> [X角度] [Z角度]` | 按 **90° 整数倍**旋转剪贴板（水平旋转只需填 Y 轴角度） |
| 镜像翻转 | `/flip` | `/cx flip [方向]` | 沿指定轴镜像翻转（省略默认当前视线朝向；可选 `east`/`west`、`north`/`south`、`up`/`down`） |

- **方块状态与实体同步**：自动换算楼梯、半砖、原木轴向、门（含左右铰链）、活板门、火把、拉杆、铁轨、告示牌等朝向，并同步变换复制偏移、大箱子配对与实体坐标朝向。
- **非法朝向保护**：若尝试绕 X/Z 轴侧翻基岩版不存在对应状态的方块（如立式告示牌或铁轨），会安全拦截并保持原剪贴板不变。

## 4.4 原理图管理

文件统一存放在运行世界一端的 `mods/creatorx/data/schematics/` 目录，单文件读取上限为 256 MiB（Java 格式按解压后大小计算）。

| 格式 | 读写能力与说明 |
| --- | --- |
| `.mcstructure` | 基岩版原生结构格式，保留方块状态、含水层、方块实体与可选非玩家实体 |
| `.cxs` | CreatorX 剪贴板格式，额外保留原始世界位置与复制时的相对站位偏移 |
| `.schem` | Sponge / WorldEdit 格式（读取 v1–v3，写入 v3） |
| `.litematic` | Java 版 Litematica 投影格式（读取支持多子区域与负尺寸，写入单区域） |

> **Java 格式说明**：`.schem` 与 `.litematic` 使用适配 Java 26.3 与基岩 26.60 的方块映射（来自 [GeyserMC/mappings](https://github.com/GeyserMC/mappings)），不支持方块实体 NBT、实体、生物群系与计划刻，部分跨版本方块属性可能被简化或跳过。

| 子命令 | 语法 | 说明 |
| --- | --- | --- |
| 导出选区 | `/cx schem export <文件> [格式] [-e]` | 直接导出当前选区（`-e` 含实体，仅基岩格式） |
| 直接放置 | `/cx schem place <文件> [格式] [-a] [-e]` | 将结构最小角放在当前脚下（`-a` 跳空气，`-e` 含实体；可 `/cx undo` 撤销） |
| 保存剪贴板 | `/cx schem save <文件> [格式]` | 将当前剪贴板存为文件 |
| 加载剪贴板 | `/cx schem load <文件> [格式]` | 读入剪贴板（之后可旋转或 `/cx paste`） |
| 列出 / 搜索 | `/cx schem list [关键词]` | 列出或按关键词筛选目录下所有支持格式的原理图 |
| 删除 | `/cx schem delete <文件> [格式]` | 删除指定原理图文件 |

省略扩展名和 `[格式]` 时，`export` / `place` 默认使用 `.mcstructure`，`save` / `load` / `delete` 默认使用 `.cxs`。文件名含空格请用英文双引号括起。
