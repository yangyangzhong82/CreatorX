# 第 1 章：快速上手与安装

本章说明 CreatorX 的运行场景、安装方式、权限规则与 5 分钟快速上手流程。

---

## 1.1 运行场景

CreatorX 提供 **服务端（server）** 与 **客户端（client）** 两个构建版本，可单端使用或双端搭配：

| 使用场景 | 服务端 | 客户端 | 可用功能 |
| --- | :---: | :---: | --- |
| **专用服务器 + 普通客户端**（手机/主机/未装模组 PC） | 已安装 | 未安装 | 全部建造功能（命令、魔杖、笔刷、图形菜单、复制粘贴、原理图、撤销重做、粒子边框、假方块预览） |
| **专用服务器 + 增强客户端** | 已安装 | 已安装 | 以上全部 + **实线选区框**、**笔刷落点标记**、**`F6`–`F10` 快捷键**、**动作栏实时 HUD** |
| **单人存档 / 局域网主机**（Windows 客户端） | — | 已安装 | 内置服务端提供完整建造功能 + 全部客户端增强体验 |
| **进入未装 CreatorX 的远程服务器** | 未安装 | 已安装 | 无法修改方块；仅提供动作栏本地坐标显示（可在配置关闭） |

---

## 1.2 安装方法

**环境要求**：Windows x64，Minecraft 基岩版 / BDS `1.26.60`（**LeviLamina `26.60.*`**）。

### 方式一：使用 lip 安装（推荐）

在服务端根目录或客户端实例目录下执行：

```powershell
# 专用服务端（BDS）
lip install github.com/yangyangzhong82/CreatorX

# Windows 客户端
lip install github.com/yangyangzhong82/CreatorX#client
```

### 方式二：手动安装

1. 从 Releases 下载对应压缩包：服务端 `CreatorX-server-windows-x64.zip`，客户端 `CreatorX-client-windows-x64.zip`。
2. 解压后将 `creatorx` 文件夹放入 `mods/` 目录：
   ```text
   mods/creatorx/
   ├─ creatorx.dll
   ├─ manifest.json
   ├─ config.jsonc
   ├─ lang/
   │  ├─ zh_CN.json
   │  └─ en_US.json
   └─ resource_packs/creatorx_shortcuts/   # 仅客户端包包含
   ```
3. 首次启动后，模组会自动将默认配置文件复制到 `mods/creatorx/config/config.jsonc`。

## 1.3 权限与命令格式

- **权限**：所有命令、魔杖与图形菜单均需玩家在游戏内拥有 **OP（`GameDirectors`）** 权限，不支持在服务端控制台直接运行。BDS 可在后台执行 `op <玩家名>` 授权；单人/局域网请开启「允许作弊」。
- **完整命令与短命令**：所有功能均挂载在 `/cx` 下。当 `config.jsonc` 中 `command.shortCommands` 为 `true`（默认开启）时，选区、编辑、剪贴板、原理图与历史命令可省略 `/cx`（例如 `/wand`、`/pos1`、`/set stone`、`/undo`）；`/cx brush`、`/cx tool` 等笔刷命令仍需带 `/cx` 前缀。
- **内置帮助**：输入 `/cx help` 查看命令索引，输入 `/cx help <命令名>` 查看具体语法。

## 1.4 5 分钟第一次建造

按照 **「选区 → 编辑 → 撤销」** 三步即可完成基础建造：

1. **领取魔杖**：输入 `/cx wand` 获取专属选区木斧。
2. **框选区域**：手持魔杖**左键**方块设点 1，**右键**对角方块设点 2，周围出现绿色选区边框。
3. **填充建造**：输入 `/cx set 60%stone_bricks,40%mossy_stone_bricks` 填充随机混搭石砖；也可直接手持魔杖**蹲下 + 右键**打开图形主菜单点选操作。
4. **调整与复制**：抬头输入 `/cx expand 5` 可向上扩高 5 格；站在结构旁执行 `/cx copy`，走到新空地执行 `/cx paste -p` 查看预览，确认无误后输入 `/cx confirm` 落地。
5. **随时撤回**：操作有误时输入 `/cx undo` 撤销（连同方块实体和实体一起恢复），输入 `/cx redo` 重做。
