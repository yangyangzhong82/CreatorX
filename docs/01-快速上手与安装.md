# 第 1 章：快速上手与安装

本章介绍 CreatorX 在不同联机/单人环境下的安装方法、权限要求，并带你用 5 分钟完成第一次快速建造。

---

## 1.1 运行场景说明

CreatorX 分为**服务端版本（server）**与**客户端版本（client）**。你可以只装一端，也可以双端同时安装以解锁完整体验：

| 使用场景 | 服务端安装 CreatorX | 客户端安装 CreatorX | 可获得的功能 |
| --- | :---: | :---: | --- |
| **场景 A：专用服务器 + 普通客户端**（手机 / 主机 / 未装模组的 PC） | 是 | 否 | **全部核心建造功能**（命令、魔杖、图形菜单、复制粘贴、原理图、撤销重做、粒子边框、粘贴假方块预览） |
| **场景 B：专用服务器 + 增强客户端** | 是 | 是 | 场景 A 全部功能 + **绿色实线选区线框** + **`F6`–`F10` 快捷键** + **动作栏实时状态 HUD** |
| **场景 C：单人存档 / 局域网房主**（Windows 客户端） | —（内置） | 是 | 客户端内置服务端直接运行完整建造功能 + 全部客户端增强体验 |
| **场景 D：进入未装 CreatorX 的远程服务器** | 否 | 是 | 无法修改方块（世界由远程服务器管理）；仅提供本地动作栏脚下坐标显示（可在配置中关闭） |

---

## 1.2 安装方法

### 前置条件
- 操作系统：**Windows x64**
- 加载器：**LeviLamina `26.60.*`**（对应 Minecraft 基岩版 / BDS `1.26.60`）

### 方式一：使用 lip 包管理器安装（推荐）

在你的服务端根目录或客户端实例目录下打开终端执行：

```powershell
# 在专用服务端（BDS）中安装
lip install github.com/yangyangzhong82/CreatorX

# 在 Windows 客户端中安装
lip install github.com/yangyangzhong82/CreatorX#client
```

### 方式二：手动下载压缩包安装

1. 前往项目 Releases 页面下载对应压缩包：
   - 服务端下载 `CreatorX-server-windows-x64.zip`
   - 客户端下载 `CreatorX-client-windows-x64.zip`
2. 解压后将 `creatorx` 文件夹放入加载器的 `mods/` 目录，最终结构如下：
   ```text
   mods/
   └─ creatorx/
      ├─ creatorx.dll
      ├─ manifest.json
      ├─ config.jsonc
      ├─ lang/
      │  ├─ zh_CN.json
      │  └─ en_US.json
      └─ resource_packs/         # 仅客户端包内含快捷键本地化资源包
         └─ creatorx_shortcuts/
   ```
3. 启动服务端或客户端。首次启动时，模组会自动将默认带注释的 `config.jsonc` 复制到 `mods/creatorx/config/config.jsonc`。

## 1.3 权限与命令格式

### 谁可以使用 CreatorX？
- 默认要求玩家拥有 **OP（操作员 / `GameDirectors`）权限**。
- 所有命令都必须在**游戏内由玩家身份执行**（因为它需要知道你的维度、朝向或选区，不支持在服务器后台黑框控制台直接敲命令）。
- 在 BDS 服务器上，服主可在后台输入 `op <玩家名>` 授予建造权限；在单人世界或局域网主机中，请确保世界设置开启了「允许作弊」且你拥有操作员权限。

### 主命令 `/cx` 与短命令机制
CreatorX 的所有功能都挂载在主命令 `/cx` 下。同时，为了贴近老玩家习惯，配置文件中默认开启了短命令开关（`command.shortCommands: true`）：

- **完整写法**（始终可用）：`/cx wand`、`/cx pos1`、`/cx set stone`、`/cx undo`
- **短命令写法**（默认开启，省去 `/cx `）：`/wand`、`/pos1`、`/set stone`、`/undo`

> 为保持清晰统一，后续文档示例统一写作 `/cx <子命令>`；你在游戏里直接输入 `/<子命令>` 效果完全一样。输入 `/cx help` 可查看所有命令列表，输入 `/cx help <命令名>`（如 `/cx help paste`）可查看该命令的语法提示。

## 1.4 5 分钟第一次建造实战

进入游戏后，跟着下面 5 步走一遍，就能掌握 CreatorX 的核心工作流：**「选区 → 执行操作 → 随时撤销」**。

### 第 1 步：领取选区魔杖
打开聊天框输入：
```text
/cx wand
```
背包里会多出一把名为 **「CreatorX 选区魔杖」** 的木斧（注意：必须是命令领取的魔杖，自己用木板合成的普通木斧默认不会触发设点，防止生存误触）。

### 第 2 步：框选一块长方体区域
把世界想象成一个长方体盒子，你只需要指定它的**两个对角顶点**：
1. 手拿魔杖，对着地面某块方块**按下左键**（破坏键）——方块不会被敲碎，聊天栏提示「已将点 1 设为 (x, y, z)」。
2. 走到斜对面或高处，对着另一个方块**按下右键**（交互键）——聊天栏提示「已将点 2 设为 (x, y, z)」。

此时两点合围的区域周围会出现**绿色边框**（装了客户端模组显示实线框，原版客户端自动显示绿色粒子棱线）。

### 第 3 步：填充或生成墙壁
现在你可以对选区做任何批量修改了。试着输入：
```text
/cx set 60%stone_bricks,40%mossy_stone_bricks
```
整个选区会立刻按 6:4 的随机比例填满石砖和苔石砖，质感非常自然！

如果不想背命令，直接拿着魔杖**蹲下（潜行）+ 按右键**，就会弹出图形化的 **CreatorX 主菜单**，点点按钮就能完成同样操作。

### 第 4 步：调整选区与复制粘贴
想把刚才建好的结构再往高处扩建？抬头看向天空输入 `/cx expand 5` 即可把选区向上拉高 5 格。
想把它搬到别处？
1. 站在建筑旁边输入 `/cx copy`（模组会记住建筑相对于你脚下的位置）。
2. 走到新空地，输入 `/cx paste -p`：眼前会先浮现出**只有你看得见的预览假方块**，并弹出确认窗口；确认位置满意后点击「执行」，建筑就真正落成了！

### 第 5 步：建错了？一键后悔
无论你是填错了方块、贴歪了房子，还是不小心清空了地面，随时输入：
```text
/cx undo
```
世界就会原封不动地恢复到操作前的样子（连箱子里的物品、告示牌上的字都会一起恢复）。如果撤多了，输入 `/cx redo` 即可重做回来。
