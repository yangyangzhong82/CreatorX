# CreatorX 使用文档

CreatorX 是基于 LeviLamina（26.60.*）的 Minecraft 基岩版快速建造模组，提供长方体选区、图形化表单菜单、方块图案与掩码、剪贴板、多步撤销/重做及分 tick 任务调度能力。

> **权限说明**：所有命令与魔杖/菜单交互均需 OP（`GameDirectors`）权限，且仅限玩家在游戏内执行（不支持控制台直接运行）。

## 1. 快速入门

### 短命令机制
当 `config.jsonc` 中的 `command.shortCommands` 为 `true`（默认开启）时，所有子命令既可以通过 `/cx <子命令>` 调用，也可以直接省略 `/cx`：
- 完整形式：`/cx pos1`、`/cx set stone`、`/cx undo`
- 短命令：`/pos1`、`/set stone`、`/undo`

### 5 步完成第一次建造
1. 执行 `/cx wand` 获取选区魔杖（默认为带特殊标记的木斧）。
2. 手持魔杖**左键点击**第一个角点方块（点 1），**右键点击**对角方块（点 2）。选区成立后，周围会自动显示绿色选区边框（仅本人可见）。
3. 执行 `/cx set 60%stone,40%andesite` 用随机石头/安山岩填充选区，或手持魔杖**蹲下右键**打开主菜单点击操作。
4. 若想调整选区边界，面向目标方向执行 `/cx expand 5` 向面朝方向扩展 5 格。
5. 建错了？执行 `/cx undo` 撤销；后悔撤销了？执行 `/cx redo` 重做。

## 2. 选区与魔杖

CreatorX 当前实现长方体选区（闭区间，包含两个角点本身）。选区与**维度**绑定：切换到不同维度设点会重置选区。

### 2.1 设点与查看命令

| 命令 | 短命令 | 参数说明 | 功能 |
| --- | --- | --- | --- |
| `/cx wand` | `/wand` | 无 | 发放一根带 NBT 标记的选区魔杖（默认 `minecraft:wooden_axe`） |
| `/cx togglewand` | `/togglewand` | 无 | 临时停用或重新启用魔杖的设点与拦截功能 |
| `/cx pos1 [x y z]` | `/pos1 [x y z]` | 坐标（可选） | 设置点 1；省略坐标时取玩家脚下方块，支持 `~` 相对坐标与 `^` 局部坐标 |
| `/cx pos2 [x y z]` | `/pos2 [x y z]` | 坐标（可选） | 设置点 2；省略坐标时取玩家脚下方块 |
| `/cx hpos1` | `/hpos1` | 无 | 将准星瞄准的方块设为点 1（最大距离由 `selection.traceDistance` 控制，默认 128 格） |
| `/cx hpos2` | `/hpos2` | 无 | 将准星瞄准的方块设为点 2 |
| `/cx size` | `/size` | 无 | 查看点 1、点 2 坐标、X/Y/Z 尺寸及总方块数 |
| `/cx desel` | `/desel` | 无 | 清除当前选区 |

> **魔杖操作提示**：
> - **左键方块**：设为点 1，取消破坏方块行为（200ms 内同一位置防连击）。
> - **右键方块**：设为点 2，取消物品/方块交互行为。
> - **蹲下 + 右键**（对准方块或空气均可）：当 `wand.sneakOpensMenu` 为 `true` 时，打开 CreatorX 主菜单（此时不会设点 2，500ms 防抖）。

### 2.2 扩展与收缩选区

| 命令 | 语法 | 说明 |
| --- | --- | --- |
| 扩展选区 | `/cx expand <格数> [反向格数] [方向]` | 向指定方向扩大选区；若填写 `[反向格数]`，同时向反方向扩大 |
| 纵向全高扩展 | `/cx expand vert` | 将选区上下边界直接延伸到当前维度的最低与最高可建造高度 |
| 收缩选区 | `/cx contract <格数> [反向格数] [方向]` | 向指定方向缩进选区（至少保留 1 格，不能缩没） |

- **方向取值**：`north`（-Z）、`south`（+Z）、`east`（+X）、`west`（-X）、`up`（+Y）、`down`（-Y）、`me`（玩家当前视线方向，含上下仰俯角）。
- 省略 `[方向]` 时默认取 `me`；也可以跳过 `[反向格数]` 直接写 `/cx expand 10 up`。
- **示例**：
  - `/cx expand 5`：向当前视线方向扩展 5 格。
  - `/cx expand 10 up`：向上扩展 10 格。
  - `/cx expand 3 2 north`：向北扩展 3 格，同时向南扩展 2 格。
  - `/cx contract 2 down`：从顶部向下缩进 2 格（收缩顶面）。

## 3. 图案（Pattern）与掩码（Mask）

### 3.1 图案语法（用于决定“放什么方块”）

图案支持多个条目用英文逗号 `,` 组合，方括号和引号内的逗号不会误切分。

| 写法 | 示例 | 说明 |
| --- | --- | --- |
| 方块 ID | `stone`、`minecraft:oak_planks` | 可省略 `minecraft:` 命名空间，大小写不敏感 |
| 带方块状态 | `wool[color=red]`、`oak_stairs["upside_down_bit"=true,"weirdo_direction"=2]` | 状态名和字符串值可加或不加引号；支持布尔值（`true`/`false`）、整数和字符串 |
| 权重随机 | `60%stone,30%cobblestone,andesite` | 按比例随机放置。未写百分比的条目平分 `100%` 剩余比例；若已写百分比总和 `>= 100`，未写百分比条目按权重 `1` 计 |
| 手持方块 | `hand`、`offhand` | 读取主手或副手当前拿着的方块（保留其方块状态） |

- **智能拼写建议**：方块名称拼错时，会自动计算编辑距离提示最接近的方块名（例如 `未知方块 'minecraft:stnoe'，你是不是想输入 'minecraft:stone'？`）。
- **禁止方块拦截**：位于 `limits.disallowedBlocks` 黑名单中的方块（默认含命令方块、结构方块、屏障）无法通过图案放置。

### 3.2 掩码语法（用于决定“哪些方块允许被修改”）

掩码由一个或多个条件词（Term）组成。**空格分隔表示“同时满足（交集）”**，条件词内部用逗号 `,` 表示“满足其一（并集）”，前缀 `!` 表示“取反”。

| 写法 | 示例 | 说明 |
| --- | --- | --- |
| 指定方块 | `stone`、`dirt,grass_block` | 匹配指定类型的方块 |
| 精确状态匹配 | `wool[color=red]` | 写了 `[...]` 时精确匹配方块状态；不写时匹配该方块 ID 的所有变体 |
| 手持方块 | `hand`、`offhand` | 匹配手持方块（含精确状态） |
| 内置关键字 | `#existing` | 匹配所有非空气方块 |
| | `#solid` | 匹配所有实心方块 |
| | `#air` | 匹配空气方块 |
| 取反前缀 `!` | `!air`、`!stone,dirt`、`!#solid` | 排除指定方块或集合 |
| 空格交集 | `!air !water`、`#solid !bedrock` | 必须同时满足所有条件 |

## 4. 区域编辑命令

执行前必须先设置好同一维度的点 1 和点 2。

| 命令 | 短命令 | 语法 | 说明 |
| --- | --- | --- | --- |
| 填充 | `/cx set` | `/cx set <pattern>` | 将整个选区填充为指定图案（输入单个方块名时支持命令自动补全） |
| 替换 | `/cx replace` | `/cx replace [from-mask] <to-pattern>` | 将选区内符合 `from-mask` 的方块替换为 `to-pattern`；省略 `from-mask` 时默认替换 `#existing`（所有非空气方块） |
| 四壁 | `/cx walls` | `/cx walls <pattern>` | 仅生成选区的四个垂直侧面（不含顶面与底面） |
| 六面外壳 | `/cx faces` | `/cx faces <pattern>` | 生成选区的全部六个外表面（内部保持不变） |
| 外壳别名 | `/cx outline` | `/cx outline <pattern>` | 与 `/cx faces` 完全相同 |

**实用示例**：
- `/cx set air`：清空选区内的所有方块。
- `/cx replace stone`：将选区内所有**非空气方块**全部替换为石头（`from-mask` 省略时默认为 `#existing`）。
- `/cx replace dirt,grass_block oak_planks`：仅把选区内的泥土和草方块替换为橡木木板。
- `/cx replace #solid !bedrock stone`：把选区内除基岩以外的所有实心方块替换为石头。
- `/cx walls 70%stone_bricks,30%cracked_stone_bricks`：用 7:3 混合石砖围出四面墙。

## 5. 剪贴板（复制 / 剪切 / 粘贴）

CreatorX 的剪贴板保存在玩家会话中，**自动保留方块第二层（如含水方块）以及箱子、告示牌、漏斗等方块实体的 NBT 数据**（暂不含生物/掉落物实体与旋转变换）。

| 命令 | 短命令 | 语法 | 说明 |
| --- | --- | --- | --- |
| 复制 | `/cx copy` | `/cx copy` | 复制选区，并记录**选区最小角相对玩家脚下坐标的偏移量** |
| 剪切 | `/cx cut` | `/cx cut [pattern]` | 复制选区后，将原选区填充为 `[pattern]`（省略时默认填为空气） |
| 粘贴 | `/cx paste` | `/cx paste [flags]` | 将剪贴板内容粘贴到世界中 |
| 清空 | `/cx clearclipboard` | `/cx clearclipboard` | 清空当前剪贴板释放内存 |

### 粘贴参数（Flags）说明
参数可以分开写（`-a -s`）也可以连写（`-as`）：
- `-a`：跳过空气，不覆盖目标位置原有的方块。
- `-o`：粘贴到**复制时的原始世界坐标**（忽略当前玩家站位）。
- `-s`：粘贴完成后，自动将选区设置为刚粘贴出来的区域范围。

> **注意事项**：
> - 复制不计入单次改动限制；**剪切**与**粘贴**会受 `limits.maxChangesPerOperation` 与大操作确认阈值限制。
> - 粘贴时若超出世界建造高度限制会拒绝执行；黑名单中的方块会被自动跳过并在完成后提示跳过的数量。

## 6. 历史记录（撤销 / 重做）与任务管理

所有对世界的修改（填充、替换、四壁、外壳、剪切、粘贴）都会生成历史记录。

| 命令 | 短命令 | 语法 | 说明 |
| --- | --- | --- | --- |
| 撤销 | `/cx undo` | `/cx undo [times]` | 撤销最近 `times` 次操作（默认 1 次），自动恢复原方块、含水层与方块实体 NBT |
| 重做 | `/cx redo` | `/cx redo [times]` | 重做最近 `times` 次被撤销的操作（默认 1 次） |
| 清空历史 | `/cx clearhistory` | `/cx clearhistory` | 清空当前玩家的撤销/重做栈 |
| 取消任务 | `/cx cancel` | `/cx cancel` | 立即中止当前正在执行的编辑/粘贴/撤销/重做任务 |

### 任务调度与取消细节
- **分 tick 异步执行**：大范围修改按 `区块列 → Y → Z → X` 顺序分批写入，受每 tick 方块上限与时间预算控制，避免服务器卡顿；未加载区块会自动临时请求加载（超时 30 秒）。
- **实时进度条**：任务运行期间，动作栏每秒刷新一次百分比、已完成/总方块数与预计剩余时间。
- **大操作弹窗确认**：预计改动数量超过 `limits.confirmThreshold`（默认 1,000,000）时，会弹出二次确认窗口防止误操作。
- **中途取消可恢复**：编辑或粘贴任务中途被 `/cx cancel` 取消时，**已经修改的方块仍会被写入历史记录**，可随时执行 `/cx undo` 恢复；若取消的是撤销/重做任务，已写回的部分进入对应栈，未写回的部分退回原栈。
- **历史保留规则**：每个玩家默认保留最近 30 条记录或最多 5,000,000 个方块（取先触发者），超出时优先丢弃旧的重做记录；**玩家退出游戏或关闭服务器时，会话、剪贴板与历史记录会被清空**。

## 7. 图形化菜单（表单 GUI）

适合手机触屏或不想记忆复杂命令与方块 ID 的玩家：

- **打开方式**：输入 `/cx menu`（或 `/menu`），或者手持魔杖**蹲下右键**，或者在客户端按下快捷键 **`F10`**。
- **主菜单功能**：实时显示当前选区坐标/尺寸、剪贴板尺寸、可撤销/重做次数与运行中的任务进度。
  - **选区**：一键设为脚下/准星方块、手动输入坐标（支持 `~` 相对坐标）、交互式滑块扩展/收缩、上下扩展到世界边界、清除选区。
  - **填充 / 四壁 / 外壳**：支持选择作用范围、下拉选取「手持方块 / 最近使用过的 10 条图案」、直接输入复杂图案，或点击**「搜索方块」**按关键词分页浏览全服所有注册方块。
  - **替换方块**：待替换掩码与目标图案均支持「最近使用（掩码与图案分开记录 10 条） / 手持方块 / 关键词搜索方块 / 手动输入」。
  - **复制 / 粘贴**：一键复制/剪切，粘贴面板提供「跳过空气」「粘贴到原位」「粘贴后选中区域」三个直观开关。
  - **撤销与重做**：一步撤销/重做、滑块选择多步撤销/重做、清空历史（带二次确认）。
  - **设置**：一键领取魔杖、开关魔杖设点拦截、开关选区线框显示。
  - **使用帮助**：内建简要操作指引。

## 8. 客户端快捷键

在客户端也安装 CreatorX 后，可在游戏「**设置 → 键盘和鼠标**」中查看或自定义键位（模组自带 `creatorx_shortcuts` 资源包提供中英文名称）。

| 默认按键 | 对应命令 | 功能 |
| --- | --- | --- |
| `F6` | `/cx hpos1` | 准星指向方块设为点 1 |
| `F7` | `/cx hpos2` | 准星指向方块设为点 2 |
| `F8` | `/cx undo` | 撤销上一步 |
| `F9` | `/cx redo` | 重做上一步 |
| `F10` | `/cx menu` | 打开 CreatorX 主菜单 |

> **联机说明**：快捷键本质上是向服务端发送对应 `/cx` 命令包，因此联机时要求**服务端也安装了 CreatorX** 且**该玩家拥有 OP 权限**。

## 9. 配置文件详解（config.jsonc）

配置文件位于模组配置目录下的 `config.jsonc`，支持 JSONC 注释。每次启动若缺少新字段会自动补齐并保留原有注释。

```jsonc
{
    "version": 1,
    "logLevel": "Info",         // 日志级别：Off, Fatal, Error, Warn, Info, Debug, Trace
    "language": "zh_CN",        // 语言文件名（对应 lang/ 目录，内置 zh_CN、en_US）

    "command": {
        "shortCommands": true   // 是否同时注册 /pos1、/set、/undo 等不带 /cx 的短命令
    },
    "limits": {
        "maxSelectionVolume": 8000000,      // 单个长方体选区的最大体积（方块数）
        "maxChangesPerOperation": 4000000,  // 单次任务允许改动的方块数上限，超出直接拒绝
        "confirmThreshold": 1000000,        // 预计改动超过该数量时弹出二次确认框
        "disallowedBlocks": [               // 禁止通过图案放置的方块（粘贴时自动跳过）
            "minecraft:command_block",
            "minecraft:chain_command_block",
            "minecraft:repeating_command_block",
            "minecraft:structure_block",
            "minecraft:barrier"
        ]
    },
    "performance": {
        "blocksPerTick": 20000, // 全服所有任务每 tick 合计最多写入的方块数
        "tickBudgetMs": 15.0,   // 全服所有任务每 tick 合计占用的时间预算（毫秒）
        "maxConcurrentJobs": 4, // 全服同时运行的任务数上限（每位玩家同一时间最多 1 个任务）
        "physics": false        // true 时写入方块会触发邻居更新（落沙、流水、红石）；false 仅同步客户端
    },
    "history": {
        "size": 30,                 // 每位玩家最多保留的撤销步数
        "maxBlocksInMemory": 5000000// 每位玩家历史记录合计方块上限，超出时淘汰最旧记录
    },
    "selection": {
        "traceDistance": 128.0  // /cx hpos1 与 /cx hpos2 射线检测最远距离（格）
    },
    "wand": {
        "item": "minecraft:wooden_axe", // 魔杖对应的物品 ID
        "requireTag": true,             // true 时仅限 /cx wand 发放的带标记魔杖有效；false 时普通同类物品也可设点
        "sneakOpensMenu": true          // true 时手持魔杖蹲下右键直接打开主菜单
    },
    "visual": {
        "mode": "auto",                         // auto / shapes：线框模式；particles：粒子模式；none：关闭
        "maxDistance": 128.0,                   // 选区边框最大渲染距离（格）
        "particle": "minecraft:villager_happy"  // particles 模式下使用的粒子 ID
    }
}
```

## 10. 常见问题与排查

- **拿着木斧点击方块没反应？**
  1. 确认自己拥有 OP（`GameDirectors`）权限。
  2. 检查是否是用 `/cx wand` 领取的魔杖（`wand.requireTag` 默认为 `true`，工作台合成的普通木斧不生效）。
  3. 检查是否误执行过 `/cx togglewand` 关闭了魔杖；可在菜单「设置」中重新启用。
- **设置了两个点但看不到选区线框？**
  1. 确认两个点在同一个维度内。
  2. 在主菜单「设置」中确认「选区线框」处于显示状态，且配置文件 `visual.mode` 不是 `none`。
  3. 若在较老版本或特殊客户端看不到线框，可将 `visual.mode` 改为 `"particles"` 切换为粒子显示。
- **为什么提示“此操作预计改动 X 个方块，超过单次 Y 个的上限”？**
  - 这是防卡服保护机制。可缩小选区、在 `config.jsonc` 中调高 `limits.maxChangesPerOperation`，或使用 `/cx walls` / `/cx faces` 代替 `/cx set`。
- **修改了 `config.jsonc` 怎么生效？**
  - 当前版本暂无 `/cx reload` 命令，修改配置后需重启服务端/客户端生效。
