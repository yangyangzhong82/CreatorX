# 第 7 章：开发者与编译指南

本章介绍 CreatorX 的模块结构、核心执行链路、数据存储格式与本地编译方法。

---

## 7.1 技术栈与构建目标

- **语言与工具链**：C++20，Windows `clang-cl`（LLVM 22）
- **构建系统**：[Xmake](https://xmake.io/) + `@levibuildscript`
- **加载器基线**：`levilamina 26.60.8`（`tooth.json` 声明 `26.60.*`，对应基岩版 / BDS `1.26.60`）
- **单仓库双目标**：
  - `--target_type=server`：定义 `LL_PLAT_S`，产出专用服务端插件。
  - `--target_type=client`：定义 `LL_PLAT_C`，产出客户端插件（含内置服务端逻辑 + 快捷键、资源包与 HUD）。

---

## 7.2 源码目录结构

```text
CreatorX/
├─ xmake.lua                  # Xmake 构建脚本（server / client 双目标）
├─ tooth.json                 # lip 发布清单（默认服务端与 #client 变体）
├─ manifest.json              # LeviLamina 模组元数据模板
├─ config.jsonc               # 默认配置文件
├─ lang/                      # 多语言文件（zh_CN.json / en_US.json）
├─ resource_packs/            # 客户端快捷键本地化资源包（creatorx_shortcuts）
└─ src/
   ├─ mod/                    # 模组生命周期入口（Entry.cpp）
   ├─ Config/                 # 反射 JSONC 配置读写与缺失项自动补齐
   ├─ I18n/                   # 多语言加载与 tr()
   ├─ core/                   # 与 MC 解耦的数学与几何结构（Vec3i、Box、BoxIterator、CuboidSelection）
   ├─ session/                # 玩家会话（选区、剪贴板、历史、笔刷绑定、最近记录、NBT 持久化）
   ├─ edit/                   # 编辑引擎（Pattern/Mask、Clipboard、ChangeSet、Jobs + ChunkAccess）
   ├─ exec/                   # 分 tick 预算调度器（JobScheduler）
   ├─ schematic/              # .cxs / .mcstructure（Schematic）与 .schem / .litematic（JavaSchematic/JavaBlocks/JavaNbt）
   ├─ storage/                # 后台单线程原子写入（.tmp + MoveFileExW 替换）
   ├─ visual/                 # 选区线框/粒子渲染（SelectionOutline）与假方块预览（PastePreview）
   ├─ net/                    # 可选增强包（creatorx:status、creatorx:brush_binding、creatorx:brush_click）
   ├─ input/                  # 快捷键注册（Shortcuts，仅 LL_PLAT_C）与笔刷/工具（BrushTools）
   ├─ ui/                     # 图形表单（Menu、AdvancedMenu、BlockBrowser）
   └─ command/                # 命令注册与参数解析（SelectionCommands / EditCommands / AdvancedCommands）
```

## 7.3 核心架构说明

### 1. 任务执行链路
1. **交互入口（`command/`、`input/` 或 `ui/`）**：校验 `GameDirectors` 权限并解析参数后构造 `exec::Job`。
2. **安全检查（`startJob`）**：检查并发上限与 `maxChangesPerOperation`；超出 `confirmThreshold` 时发送 `ModalForm` 二次确认（校验 `generation` 与维度防止失效回调）。
3. **分片调度（`exec::JobScheduler` + `edit::ChunkAccess`）**：每 tick 按活动任务数均分 `blocksPerTick` 与 `tickBudgetMs`。`BoxIterator` 按 `区块列 → Y → Z → X` 遍历；遇到未加载区块时通过临时 `ChunkViewSource` 异步加载（30 秒超时保护）。
4. **调色板变更记录（`edit::ChangeSet`）**：`writeBlock()` 自动保存旧方块、含水第二层、方块实体 NBT 与实体变更，调色板去重压缩后在任务结束（包括 `/cx cancel` 中止）时压入 `History`。

### 2. 原子持久化与溢写
- **线程隔离**：`BlockSource` / `Actor` 读写严格在服务端主线程；后台 `storage::Writer` 仅处理值拷贝的 `CompoundTag` 或字节流。
- **原子写入**：先写 `<目标>.tmp`，再通过 `MoveFileExW(..., MOVEFILE_REPLACE_EXISTING | MOVEFILE_WRITE_THROUGH)` 原子替换。
- **数据目录（`mods/creatorx/data/`）**：
  - `schematics/`：原理图文件（`.cxs` / `.mcstructure` / `.schem` / `.litematic`）
  - `history-cache/`：超内存阈值后溢写落盘的 `ChangeSet`
  - `players/<levelIdHex>/`：`<uuid>.nbt`（历史引用、偏好、最近图案/掩码）与 `<uuid>.clipboard.nbt`

### 3. 双端可选增强协议（`net/Enhancements.cpp`）
- 使用 `Optional = true` 注册自定义包 `creatorx:status`、`creatorx:brush_binding`、`creatorx:brush_click`。
- 服务端通过 `canSendTo(player)` 判断客户端是否装有 CreatorX：增强客户端启用实线选区框、笔刷落点提示、鼠标直发点击包与动作栏 HUD；普通客户端自动降级为粒子边框。

## 7.4 本地编译

**前置条件**：Windows 10/11 x64、Visual Studio 2022（C++ 桌面开发）、LLVM/Clang 22（`clang-cl` 在 `PATH` 中）、最新版 Xmake。

```powershell
# 更新仓库索引
xmake repo -u

# 编译服务端版本
xmake f -p windows -a x64 -m release --toolchain=clang-cl --target_type=server -y
xmake -y

# 编译客户端版本
xmake f -p windows -a x64 -m release --toolchain=clang-cl --target_type=client -y
xmake -y
```

产物输出在 `bin/creatorx/`（服务端包含 `creatorx.dll`、`config.jsonc`、`lang/`；客户端额外包含 `resource_packs/creatorx_shortcuts/`）。

## 7.5 扩展开发要点

1. **新增配置项**：在 `src/Config/Config.h` 添加字段（新增结构体需特化 `is_reflectable<T>`），在 `src/Config/ConfigManager.cpp` 的 `normalizeConfig()` 中做范围校验，并更新根目录 `config.jsonc`。
2. **新增语言词条**：同步更新 `lang/zh_CN.json` 与 `lang/en_US.json`，代码中使用 `tr("key", args...)`。
3. **新增编辑任务**：继承 `exec::Job` 实现 `total()`、`progress()`、`run()` 与 `finish()`，并在 `command/` 与 `ui/` 注册入口。
