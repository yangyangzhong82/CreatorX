# 第 5 章：图形菜单与客户端增强

在手机触屏、手柄或者懒得敲英文方块 ID 的场景下，CreatorX 提供了覆盖全部核心功能的**原生表单图形界面（GUI）**；如果你使用的是安装了 CreatorX 的 Windows 客户端，还能进一步解锁**自定义键盘快捷键**与**动作栏实时状态 HUD**。

---

## 5.1 如何打开主菜单？

你有 **3 种方式**随时唤出 CreatorX 主菜单：

1. **魔杖快捷手势（最顺手）**：手拿选区魔杖，**潜行（蹲下）+ 点击右键**（对着空气或方块都能触发）。
2. **客户端快捷键**：在 PC 客户端直接按下 **`F10`**（支持在游戏设置里改键）。
3. **输入聊天命令**：输入 `/cx menu`（开启短命令时直接输 `/menu`）。

---

## 5.2 图形主菜单全功能导览

打开主菜单后，顶部面板会一目了然地展示你当前的**选区坐标与体积**、**剪贴板尺寸**、**可撤销/可重做步数**以及**正在运行的后台任务百分比**（如果有可撤销记录或进行中的任务，主菜单还会动态出现「撤销上一步」与「取消当前任务」快捷按钮）。

各子面板功能如下：

### 1. 选区（Selection）
- **一键设点**：站在目标位置点「点 1 / 点 2 设为脚下」，或对准远处点「设为准星方块」。
- **输入坐标**：手动填写精确坐标，支持 `~ ~-1 ~5` 这类相对坐标。
- **扩展 / 收缩**：通过下拉框选择扩展或收缩、选择方向（含「我面朝的方向」），并用滑块直观拉取格数与反方向格数。
- **平移 / 外扩 / 内缩选区**：图形化执行 `shift`、`outset`、`inset`。
- **上下扩展到世界边界 / 清除选区**：一键贯通天地或清空重选。

### 2. 填充 / 四壁 / 外壳（Fill）与 替换方块（Replace）
完全告别死记硬背英文方块名！表单中的方块来源下拉框提供 4 种便捷选法：
- **手持方块（默认优先选中）**：直接读取你手里正拿着的方块。
- **最近使用记录（自动记忆 10 条）**：你用过的复杂权重图案（如 `60%stone,40%andesite`）和掩码会**分开各存最近 10 条**，下次点开下拉框直接复用，重进游戏也不会丢！
- **内置搜索方块器**：在下拉框选中 **「搜索方块」** 并点提交，输入任意关键词（如 `brick`、`slab`、`oak`，留空则浏览全服全部方块），每页 24 个按钮分页展示，点一下就自动填回刚才的表单！
- **手动输入框**：随时手写高级百分比图案或组合掩码；若语法输错，会保留你刚填的内容重新打开表单并用红字标出错误原因，不用重头再填。

### 3. 形状与更多编辑（Build）
集中提供 **12 种进阶建造与统计操作**的表单入口：
- **几何生成**：实心球/椭球、空心球、实心圆柱、空心圆柱、实心金字塔、空心金字塔（填图案、半径/层数、圆柱高度即可）。
- **进阶区域操作**：掏空（`hollow`）、覆盖表层（`overlay`）、移动区域（`move`）、堆叠区域（`stack`，带「跳过空气」与「粘贴后选中」开关）。
- **选区统计**：统计掩码匹配数量（`count`）、统计方块分布（`distr`）。

### 4. 复制 / 粘贴（Clipboard）
- **一键复制 / 剪切**，以及 **「复制 / 剪切选项」**（可开关「包含实体」、填写过滤掩码与剪切后留下的方块）。
- 当剪贴板有内容时，自动解锁：
  - **粘贴面板**：提供直观的开关按钮——「跳过空气」（默认开）、「粘贴到复制时的原位置」、「粘贴后选中粘贴区域」（默认开）、「**先预览并确认落点**」（默认开，强烈推荐！）、「包含实体」以及过滤掩码输入框。
  - **旋转 / 翻转剪贴板**：下拉选择旋转或翻转，输入绕 Y / X / Z 轴度数（90° 倍数）或选择翻转轴。
  - **原理图管理**：表单顶部直接列出当前所有原理图文件，下拉选择「保存剪贴板 / 加载到剪贴板 / 删除原理图」（删除带二次确认弹窗），可选 `cxs` 或 `mcstructure` 格式。

### 5. 撤销与重做（History）与 设置（Settings）
- **撤销与重做**：顶部列出每一条历史操作的类型、改动方块数与精确时间戳；支持单步撤销/重做、拖动滑块**多步批量撤销/重做**，以及带二次确认的清空历史。
- **设置**：一键领取魔杖、**热重载配置文件（`reload`）**、切换魔杖启用/停用、切换选区线框显示/隐藏。

## 5.3 客户端快捷键（仅 Windows 客户端安装后可用）

在 Windows 客户端安装 CreatorX 后，模组会自动向原版键位系统注册 5 个高频快捷键，并附带 `creatorx_shortcuts` 资源包提供中文名称。你可以随时进入游戏 **「设置 → 键盘和鼠标」** 拉到底部修改为你顺手的按键：

| 默认按键 | 游戏设置内显示名称 | 实际发送的命令 | 作用 |
| :---: | --- | --- | --- |
| **`F6`** | CreatorX · 准星设为点 1 | `/cx hpos1` | 将十字准星瞄准的远处方块直接设为点 1 |
| **`F7`** | CreatorX · 准星设为点 2 | `/cx hpos2` | 将十字准星瞄准的远处方块直接设为点 2 |
| **`F8`** | CreatorX · 撤销 | `/cx undo` | 立即撤销上一步操作 |
| **`F9`** | CreatorX · 重做 | `/cx redo` | 立即重做上一步被撤销的操作 |
| **`F10`** | CreatorX · 打开主菜单 | `/cx menu` | 随时弹出 CreatorX 图形主菜单 |

> **联机工作原理说明**：按下快捷键时，客户端会自动向服务端发送对应的 `/cx` 命令请求包，由服务端校验权限并执行。因此联机游玩时，需要**服务端同样安装了 CreatorX** 且你的账号**拥有 OP 权限**。

---

## 5.4 客户端动作栏实时 HUD

当客户端安装了 CreatorX 且 `config.jsonc` 中 `client.hud` 为 `true`（默认开启）时，屏幕下方的动作栏（Actionbar）会为你提供轻量、不遮挡视野的状态提示：

1. **在安装了 CreatorX 的世界 / 服务器中**（双端自定义 `creatorx:status` 协议自动握手）：
   每秒同步刷新你的实时工作台状态，格式如下：
   ```text
   CreatorX | 选区 24×12×18 | 剪贴板 10×8×10 | 撤销 5 / 重做 0
   ```
   当后台有大型建造任务运行时，末尾会自动切换为实时进度 `| 任务 68%`。
2. **在未安装 CreatorX 的第三方普通服务器中**：
   若 `client.localCoordinates` 为 `true`（默认开启），动作栏会贴心地退回为本地脚下整数坐标指示器：
   ```text
   CreatorX | 坐标 128 64 -350
   ```
   如果不想在普通服务器看到坐标栏，在本地客户端的 `config.jsonc` 中将 `"localCoordinates": false`（或 `"hud": false`）改掉即可。
