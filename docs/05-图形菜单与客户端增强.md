# 第 5 章：图形菜单与客户端增强

不方便打字或记不住英文方块 ID 时，可通过图形表单完成全部核心操作；Windows 客户端安装 CreatorX 后还可额外使用快捷键与动作栏状态 HUD。

---

## 5.1 打开主菜单

- **魔杖手势**：手持选区魔杖，**蹲下 + 右键**。
- **快捷键**（仅增强客户端）：按 **`F10`**。
- **命令**：输入 `/cx menu`（短命令 `/menu`）。

---

## 5.2 主菜单功能一览

主菜单顶部显示当前**选区尺寸**、**剪贴板尺寸**、**可撤销/重做步数**以及**运行中任务进度**，并根据当前状态动态显示「撤销上一步」「取消当前任务」及远程设点按钮。

### 1. 选区（Selection）
- **设点**：点 1 / 点 2 设为脚下、设为准星方块，或手动输入绝对/相对/局部坐标。
- **调整选区**：图形化执行 `expand`、`contract`、`shift`、`outset`、`inset`、`expand vert` 与 `desel`。

### 2. 填充 / 四壁 / 外壳 与 替换方块（Fill / Replace）
图案与掩码下拉框提供以下选择方式：
- **手持方块**：默认优先读取主手或副手正在拿着的方块。
- **最近使用**：图案与掩码**分开各记忆最近 10 条**复杂表达式，随账号持久化保存。
- **分类方块浏览器**：选择 **「浏览 / 搜索方块」** 并提交，可按「常用方块」「最近使用」「石材与矿物」「木材与竹材」「自然与地形」「彩色建材」「玻璃与照明」「装饰与构件」「功能与红石」「全部方块」分类浏览，支持实时搜索与分页列表回退，点选即自动填回表单。
- **手动输入**：留空时使用下拉框所选；若语法输错，会保留原输入重新弹窗并用红字提示错误原因。

### 3. 形状与更多编辑（Build）
集成 **13 种** 进阶操作表单：
- **几何形状**：`sphere`、`hsphere`、`cyl`、`hcyl`、`pyramid`、`hpyramid`（支持「以选区中心为生成点」开关、球体「抬高」开关与可选掩码）。
- **区域操作**：`hollow`、`overlay`、`center`、`move`、`stack`。
- **选区/剪贴板统计**：`count`、`distr`。

### 4. 复制 / 粘贴（Clipboard）
- **复制 / 剪切**：提供一键复制/剪切，以及带「包含实体」「过滤掩码」「剪切后填入图案」的高级选项表单。
- **粘贴与预览管理**：剪贴板非空时可打开粘贴表单（含「跳过空气」「原位粘贴」「粘贴后选中」「先预览并确认落点」「包含实体」与过滤掩码）；预览期间可直接点击「确认粘贴」「调整预览落点」「取消预览」。
- **旋转 / 翻转**：图形化绕 Y/X/Z 轴旋转 90° 倍数或按方向镜像翻转。
- **原理图管理**：分页浏览、按关键词搜索、加载到剪贴板、直接放置到脚下、删除文件，以及将当前选区导出或将剪贴板保存为 `cxs` / `mcstructure` / `schem` / `litematic`。

### 5. 撤销与重做（History）与 设置（Settings）
- **撤销与重做**：列出可撤销/重做历史摘要，支持单步撤销/重做、滑块多步批量撤销/重做与二次确认清空历史。
- **设置**：
  - **领取选区魔杖**、**重新加载配置（`reload`）**、**停用/启用魔杖**、**显示/隐藏选区线框**。
  - **远程魔杖**：启用后对着空气挥动或右键使用魔杖可沿视线设点，且主菜单会显示快捷视线设点按钮。
  - **HUD 设置**：独立开关动作栏 HUD，并可调整闲置自动隐藏秒数（`5–60` 秒，默认 `15` 秒）。

---

## 5.3 客户端快捷键（仅 Windows 客户端）

安装客户端版后，游戏 **「设置 → 键盘和鼠标」** 底部会注册以下可自定义键位：

| 默认按键 | 游戏内名称 | 触发命令 | 作用 |
| :---: | --- | --- | --- |
| `F6` | CreatorX · 准星设为点 1 | `/cx hpos1` | 准星指向方块设为点 1 |
| `F7` | CreatorX · 准星设为点 2 | `/cx hpos2` | 准星指向方块设为点 2 |
| `F8` | CreatorX · 撤销 | `/cx undo` | 撤销上一步 |
| `F9` | CreatorX · 重做 | `/cx redo` | 重做上一步 |
| `F10` | CreatorX · 打开主菜单 | `/cx menu` | 打开图形主菜单 |

> 按下快捷键时由客户端向服务端发送命令请求，因此联机时需服务端也安装 CreatorX 且自身拥有 OP 权限。

---

## 5.4 客户端动作栏实时 HUD

在 `config.jsonc` 中保持 `client.hud: true`（默认开启）时：

- **在已安装 CreatorX 的世界 / 服务器中**：进行设点、编辑、菜单或快捷键操作后，动作栏会显示当前工作台摘要（选区尺寸、剪贴板尺寸、撤销/重做次数），并在闲置超过设定秒数（默认 `15` 秒）后自动隐藏；后台任务运行时由任务进度条显示百分比与预计剩余时间。
- **在未安装 CreatorX 的第三方服务器中**：若 `client.localCoordinates: true`（默认开启），按键触发后动作栏会短暂显示脚下整数坐标，闲置 `15` 秒后自动隐藏。不需要时可在客户端 `config.jsonc` 将 `localCoordinates` 或 `hud` 设为 `false`。
