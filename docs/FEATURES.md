# CreatorX 功能清单

> 架构与实现细节见 [DESIGN.md](DESIGN.md)。
>
> **优先级**：P0 = MVP 必须；P1 = v0.2–v0.3；P2 = v0.4–v1.0；P3 = 以后再说。
> **端**：S = 服务端（含单人内置服务端）；C = 仅客户端增强。
> **风险**：标 ⚠ 的依赖某个 Spike（见 DESIGN.md §15）的结论。
> **命令写法**：下表统一写成 `//xxx`。实际可用三种形式：`//xxx`（聊天拦截，⚠S3）、`/cx xxx`（始终可用）、`/xxx`（短命令，可关闭）。
