# 第 6 章：历史记录、配置与服主指南

本章面向服主与管理员，说明历史恢复与磁盘溢写、分 tick 异步调度、`config.jsonc` 配置项与常见问题排查。

---

## 6.1 历史记录与撤销管理

所有修改方块或实体的操作（含区域编辑、几何生成、剪贴板粘贴、笔刷、原理图放置）均会记录原方块、含水第二层、方块实体 NBT 及受影响实体。

| 命令 | 短命令 | 语法 | 说明 |
| --- | --- | --- | --- |
| 撤销 | `/undo` | `/cx undo [步数] [玩家名或UUID]` | 撤销最近操作（默认 `1` 步）；管理员可指定玩家名或离线 UUID 回滚他人操作 |
| 重做 | `/redo` | `/cx redo [步数] [玩家名或UUID]` | 重做最近被撤销的操作，同样支持指定他人 |
| 历史列表 | `/history` | `/cx history` | 查看当前可撤销与可重做记录（操作类型、改动数、时间） |
| 清空历史 | `/clearhistory` | `/cx clearhistory` | 清空自己的撤销与重做记录 |
| 中止任务 | `/cancel` | `/cx cancel` | 中止正在执行的任务，或取消粘贴预览 |
| 热重载 | `/reload` | `/cx reload` | 重新加载 `config.jsonc`、语言文件、黑名单与可视化选项 |

### 持久化与磁盘溢写
- **内存溢写**：每位玩家内存中默认最多保留 `5,000,000` 个历史方块（`history.maxBlocksInMemory`）。超出部分由后台线程异步序列化到 `mods/creatorx/data/history-cache/` 并释放内存，`/cx undo` 时再按需读回。
- **离线保留**：玩家历史索引、剪贴板、最近 10 条图案/掩码与个人偏好（魔杖/线框/HUD 设置）按存档保存在 `mods/creatorx/data/players/<世界ID>/<UUID>.nbt`，重启或重进服后依然可用。模组启动时会自动清理无引用的孤立缓存文件。
- **安全取消**：任务运行中被 `/cx cancel` 中止或玩家掉线时，**已写入世界的部分仍会生成一条合法历史记录**，可直接 `/cx undo` 撤回。

## 6.2 分 Tick 调度与安全限制

1. **双预算分片**：全服活动任务平分每 tick 的方块上限（`performance.blocksPerTick`，默认 `20,000`）与毫秒预算（`performance.tickBudgetMs`，默认 `15.0` ms）；每位玩家同时最多运行 `1` 个任务，全服并发上限默认 `4`（`performance.maxConcurrentJobs`）。
2. **区块局部遍历与自动加载**：按 `区块列 → Y → Z → X` 顺序遍历。遇到未加载区块时自动创建临时加载视图等待就绪（超时 `30` 秒或越界时安全中止并保留已完成部分供撤销）。
3. **物理更新抑制（`performance.physics: false`）**：默认写入方块仅同步客户端画面，不触发落沙、流水、红石等邻居物理更新；需要原版物理响应时可设为 `true`。
4. **三级限额保护**：选区体积上限（`8,000,000`）、单次改动上限（`4,000,000`）与大操作弹窗确认阈值（`1,000,000`）。

## 6.3 配置文件说明（`config.jsonc`）

配置文件位于 `mods/creatorx/config/config.jsonc`，支持 `//` 与 `/* */` 注释。版本更新若新增配置项，模组会自动补齐缺失键并保留原有注释。修改后执行 `/cx reload` 立即生效（仅 `command.shortCommands` 需重启生效）。

```jsonc
{
    // 配置格式版本，保持为 1 即可。
    "version": 1,

    // 日志级别：Off、Fatal、Error、Warn、Info、Debug、Trace。
    "logLevel": "Info",

    // 语言文件名（对应 lang/ 目录下的 zh_CN、en_US）。
    "language": "zh_CN",

    "command": {
        // 是否注册 /pos1、/set、/undo 等省略 /cx 的短命令（修改后需重启生效）。
        "shortCommands": true
    },

    "limits": {
        // 单个选区最大允许体积（方块数）。
        "maxSelectionVolume": 8000000,
        // 单次操作最大允许改动方块数，超过直接拒绝。
        "maxChangesPerOperation": 4000000,
        // 预计改动超过此数时弹出确认窗口。
        "confirmThreshold": 1000000,
        // 禁止通过图案放置的方块列表（粘贴与堆叠时自动跳过）。
        "disallowedBlocks": [
            "minecraft:command_block",
            "minecraft:chain_command_block",
            "minecraft:repeating_command_block",
            "minecraft:structure_block",
            "minecraft:barrier"
        ]
    },

    "performance": {
        // 全服每 tick 合计最多写入方块数（读取预算按 4:1 折算）。
        "blocksPerTick": 20000,
        // 全服每 tick 合计最多占用的主线程毫秒数（0.1 ~ 100.0）。
        "tickBudgetMs": 15.0,
        // 全服同时运行的任务数上限（每人同时最多 1 个）。
        "maxConcurrentJobs": 4,
        // true：触发邻居物理更新（落沙、流水、红石）；false：仅同步客户端。
        "physics": false
    },

    "history": {
        // 每位玩家最多保留的可撤销步数。
        "size": 30,
        // 每位玩家内存中驻留的历史方块数上限，超出自动溢写到磁盘。
        "maxBlocksInMemory": 5000000
    },

    "selection": {
        // /cx hpos1 与 /cx hpos2 准星射线检测最远距离（1.0 ~ 512.0 格）。
        "traceDistance": 128.0
    },

    "wand": {
        // /cx wand 发放的魔杖物品 ID。
        "item": "minecraft:wooden_axe",
        // true：仅 /cx wand 发放的带标记魔杖可设点；false：同款普通物品也可设点。
        "requireTag": true,
        // true：手持魔杖蹲下右键直接打开主菜单。
        "sneakOpensMenu": true
    },

    "visual": {
        // auto：增强客户端显示实线框，其余显示粒子；shapes：强制线框；particles：强制粒子；none：关闭。
        "mode": "auto",
        // 边框最大渲染距离（0 ~ 512.0 格）。
        "maxDistance": 128.0,
        // 粒子模式使用的粒子 ID。
        "particle": "minecraft:villager_happy",
        // 粘贴预览（-p）不超过此体积时发送假方块，超过时仅显示边界框（0 ~ 32768）。
        "previewMaxBlocks": 4096,
        // 粘贴预览持续秒数，超时自动清除（5 ~ 120 秒）。
        "previewSeconds": 30
    },

    "client": {
        // （仅客户端）是否启用动作栏 CreatorX 状态 HUD。
        "hud": true,
        // （仅客户端）在未安装 CreatorX 的远程服务器中是否显示本地脚下坐标。
        "localCoordinates": true
    }
}
```

## 6.4 常见问题（FAQ）

1. **拿木斧敲方块没设点，反而敲碎了方块？**
   - 确认拥有 OP（`GameDirectors`）权限。
   - 默认 `wand.requireTag: true`，普通木斧无效，请用 `/cx wand` 领取专属魔杖。
   - 检查是否停用了魔杖（输入 `/cx togglewand` 或在菜单「设置」恢复启用）。

2. **设好了点 1 和点 2，看不见绿色选区边框？**
   - 确认两点在**同一维度**。
   - 检查 `/cx menu` → **「设置 → 选区线框」** 是否为「显示」，且 `visual.mode` 不为 `"none"`。
   - 原版客户端若在视频设置中关闭了粒子，也会隐藏粒子边框。

3. **提示改动数超出上限怎么办？**
   - 分批框选，或使用 `/cx walls`、`/cx faces`。
   - 服主可在 `config.jsonc` 调高 `limits.maxSelectionVolume` 与 `limits.maxChangesPerOperation` 后执行 `/cx reload`。

4. **短命令（如 `/set`）与其他插件冲突怎么办？**
   - 始终使用带前缀的 `/cx set`，主命令 `/cx` 不会与短命令冲突。

5. **低配服务器执行大任务掉帧怎么调整？**
   - 将 `performance.blocksPerTick` 降为 `8000`、`performance.tickBudgetMs` 降为 `8.0`，执行 `/cx reload` 即可。
